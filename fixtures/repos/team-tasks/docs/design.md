# Task board design (EVALUATION FIXTURE)

## Tasks
- A task has **one assignee**, an optional due date and a status: open, done or archived.
- Only the assignee, the creator or an admin can edit a task.

## Reminders
- Reminders are sent **24 hours before** a task's due date.
- Reminders go to the assignee only.

## Comments
- Comments can mention users with `@username`. Mentioned users are notified.
